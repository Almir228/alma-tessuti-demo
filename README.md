# Alma Tessuti Demo

Статическая демонстрационная витрина Alma Tessuti для GitHub Pages.

[Открыть демонстрацию](https://almir228.github.io/alma-tessuti-demo/) · [Зачем создан проект и какую проблему он решает](docs/PROJECT_OVERVIEW.md)

Проект показывает, как превратить Telegram-канал магазина в структурированную
витрину: покупателю больше не нужно искать товар среди старых сообщений, а
продавцу — вручную переносить весь ассортимент в отдельный интернет-магазин.

## Возможности

- 26 отобранных товаров из локального каталога;
- оптимизированные WebP-изображения;
- категории и сортировка по цене;
- поиск по названию, материалу и цвету;
- галерея и выбор размера;
- демонстрационная корзина в браузере;
- адаптивная версия для телефона и компьютера.

Демо не содержит Python-приложение, базу SQLite, Telegram API-ключи, пользовательские сессии или административную часть. Заказы и персональные данные не принимаются.

## Локальный просмотр

```bash
python3 -m http.server 8080
```

Открыть `http://127.0.0.1:8080`.

## Публикация

Workflow `.github/workflows/pages.yml` публикует содержимое ветки `main` в GitHub Pages.
